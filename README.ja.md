DComEasy は、産業現場での導入、試運転、保守に向けた Windows 用の OPC DA / DCOM 設定・診断ツールです。環境診断、DCOM アクセス権限の設定、OPC DA 接続テスト、タグの監視、ネットワークチェック、診断レポートの作成を、ひとつの画面で行えます。

> [!TIP]
> **完全オフライン対応**：DComEasy のインストール、ライセンス認証、およびすべてのローカル機能は、インターネット接続なしで利用できます。

> [!IMPORTANT]
> DComEasy はプロプライエタリソフトウェアです。このリポジトリは、公式リリース、ユーザードキュメント、不具合報告のために公開しており、製品のソースコードは含まれていません。ソフトウェアのダウンロードまたは使用により、リリースパッケージに同梱されたライセンス条項に同意したものとみなされます。

## 動作デモ

診断とライセンスの確認から始め、OPC ユーザーの設定、接続テスト、タグの参照を行い、複数タグの監視タスクとリアルタイムトレンドを確認します。デモは英語版の画面とサンプルデータを使用しており、実際のアカウント、アクティベーションコード、サーバー情報は含まれていません。

## 主な機能

- <img src="assets/icon-diagnosis.svg" width="20" height="20" alt=""> **設定診断**：ローカル設定、アプリケーションの実行ユーザー、DCOM ロールのアクセス権限、OPC コンポーネントとその登録状態を確認できます。
- <img src="assets/icon-users.svg" width="20" height="20" alt=""> **ユーザー管理**：OPC 認証情報を自動的に検証し、ひとつのメニューから管理対象のローカルアカウントの作成・削除や認証情報の消去を行えます。既存ユーザーのパスワードを上書きしたり、リセットしたりすることはありません。
- <img src="assets/icon-settings.svg" width="20" height="20" alt=""> **設定管理**：DCOM アクセス権限、既定の認証レベル、プロトコルの順序を調整できます。変更内容のプレビューを個別に実行し、確認後に適用できます。
- <img src="assets/icon-settings.svg" width="20" height="20" alt=""> **設定テンプレート**：Pro と Enterprise では、設定とユーザー認証情報を暗号化された `.dc` ファイルにエクスポートし、別のコンピューターで内容を確認して適用できます。
- <img src="assets/icon-components.svg" width="20" height="20" alt=""> **コンポーネントの導入**：必要に応じて OPC ランタイム環境をインストールまたは修復し、OPCEnum とオートメーションコンポーネントを利用可能にします。
- <img src="assets/icon-connection.svg" width="20" height="20" alt=""> **サーバー検出と接続テスト**：設定した OPC ユーザーで、ローカルまたは接続先ホストに登録された OPC DA サーバーを検出できます。ProgID / CLSID の手動入力にも対応しています。失敗時には原因と対処方法を表示し、ネットワークチェックの結果、失敗した段階、エラーコード、元のエラーを接続履歴で確認できます。
- <img src="assets/icon-connection.svg" width="20" height="20" alt=""> **タグの参照と監視**：必要に応じて階層を展開し、完全な ItemID で検索できます。単発の読み取りや、個別・一括での更新間隔の設定に対応し、値、品質、タイムスタンプ、読み取りエラーを確認できます。ブール値は `0/1` で表示されます。
- <img src="assets/icon-report.svg" width="20" height="20" alt=""> **監視タスク**：空のタスクを作成してからタグを追加できます。タスク一覧を更新すると、ディスク上の変更が反映されます。監視を開始せずにリアルタイムトレンドを確認でき、数値のトリガールールをすべて設定した後は、共通の周期でタグを一括収集し、イベント対象期間の PDF・CSV レポートを自動保存できます。
- <img src="assets/icon-report.svg" width="20" height="20" alt=""> **接続履歴**：成功・失敗の記録を保存し、再起動後に直近の接続先情報を復元します。右クリックメニューから接続情報の再入力や記録の削除を行え、削除後もスクロール位置を保持します。パスワードは保存しません。
- <img src="assets/icon-settings.svg" width="20" height="20" alt=""> **ネットワークツール**：リモートチェックでは接続先への疎通状況を表示します。ローカルチェックでは、ローカルの待ち受けポートとファイアウォール規則も確認できます。ローカルの TCP / UDP 受信ポート規則を一括追加できます。
- <img src="assets/icon-report.svg" width="20" height="20" alt=""> **診断レポート**：トラブルシューティング、引き継ぎ、記録保管に利用できる PDF または HTML を出力します。
- <img src="assets/icon-language.svg" width="20" height="20" alt=""> **2 言語のユーザーインターフェース**：サイドバーで簡体字中国語と英語を切り替えられ、選択した言語は保存されます。

## オフラインライセンス認証

クライアントは常にオフラインライセンス認証を使用し、導入先で Web サイトやインターネットへの接続は必要ありません。すべての公式リリースにこのライセンス方式が適用されます。未認証の場合は Free エディションとして動作し、有効なアクティベーションコードを入力すると、Pro または Enterprise に割り当てられた機能が有効になります。

| エディション | 認証要件 | 現在利用できる機能 |
|---|---|---|
| Free | コード不要。クライアントの初期状態 | 診断、ユーザー検証、変更内容のプレビュー、基本的な OPC 接続・参照・単一タグの読み取り、ネットワーク状態の確認、履歴、ログ。PDF レポートには Free の透かしが入ります |
| Pro | 32 文字の Pro アクティベーションコード | すべての機能。PDF・HTML レポートは透かしなし |
| Enterprise | 32 文字の Enterprise アクティベーションコード | 現在は Pro と同等。将来個別に調整できるよう、権限は別途管理されます |

アクティベーションコードは 4 文字ずつの 8 グループで構成され、エディション、一意のライセンス ID、初回認証期限、任意の利用期限、申請情報のダイジェストを含みます。初回認証期限は、新しいデバイスでの初回認証のみを制限します。認証済みのデバイスでは、別途設定された利用期限に基づいて検証が行われます。

### 無料の Pro アクティベーションコード

以下の 3 つのコードは無料で利用できます。初回認証期限と利用期限はいずれも **2026-12-31** です。

| ライセンス ID | アクティベーションコード |

| PRO-0000001569 | `444Z-R2FW-0000-C89X-PKHP-CS53-SPVC-AZPB` |
| PRO-0000001570 | `444Z-R2FW-0000-C8HX-PKHP-CS5E-N5J3-WRAR` |

## 動作要件

- 64 ビット版 Windows に対応しています。OPC DA および関連する COM コンポーネントとの互換性のため、DComEasy は 32 ビットプロセスとして動作します。
- インストールと実行には管理者権限が必要です。
- 必要な .NET ランタイムを含む、完全なオフラインインストーラーを使用してください。
- 接続テストには、アクセス可能な OPC DA サーバーと、その環境で有効な OPC ユーザーの認証情報が必要です。

## ダウンロードとインストール

1. [Releases](https://github.com/Todayos/DComEasy-Releases/releases/latest) から公式インストーラーをダウンロードします。
2. インストーラーを管理者として実行します。
3. スタートメニューから DComEasy を起動し、案内に従って管理者権限で実行します。

新しいバージョンをインストールする際に、旧バージョンを事前にアンインストールする必要はありません。DComEasy を終了し、新しいインストーラーを管理者として実行してください。インストール先の選択画面には現在のインストール先が表示されます。そのまま指定すると上書き更新でき、別の空のフォルダーを選ぶこともできます。ライセンスの状態、ログ、接続履歴、ユーザー所有のファイルは保持されます。

このリポジトリの GitHub Releases で公開されたインストーラーを使用してください。出所不明のインストーラーをダウンロードしたり、インストールフォルダー内の実行ファイルだけをコピーしたりしないでください。

インストーラーと対応する SHA-256 チェックサムは、[公式 Releases](https://github.com/Todayos/DComEasy-Releases/releases/latest) で確認できます。

SHA-256 チェックサムを公開しても、ソースコード、ライセンスキー、アクティベーションコードの生成方法が漏れることはありません。チェックサムは、ファイルの破損や差し替えの有無を確認するためのものです。チェックサムだけでは発行元の身元を証明できません。インストーラーと公開されたチェックサムの両方が差し替えられた場合、比較に成功する可能性があります。このリポジトリの公式 Release からのみダウンロードしてください。インストーラーを再ビルドするとチェックサムも変わるため、対応する Release に掲載された値を使用してください。

詳しい操作方法は、[ユーザーガイド（英語）](docs/usage.en.md)を参照してください。
