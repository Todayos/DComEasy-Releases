# 使用指南

[项目首页](../README.md) · 简体中文 | [English](usage.en.md) · [License](../LICENSE)

## 启动与界面语言

以管理员身份运行离线安装包 `DComEasy-Setup-v2.0.3.exe`，首次安装时可以选择目录，默认是 32 位 Program Files 下的 `DComEasy`。建议选择本机各账号都能读取和执行的目录，不要选 Downloads、个人桌面等仅当前用户可访问的位置，否则换账号连接探测仍可能因工作目录权限失败。目标目录必须为空；如果所有用户桌面或开始菜单已有同名 DComEasy 快捷方式，先检查并改名或移走，安装器不会覆盖它。安装新版时无需卸载旧版：关闭正在运行的 DComEasy 后，以管理员身份直接运行新版安装包。安装器仍会显示目录选择页，并默认填入已登记的原安装目录；保留该目录会原地覆盖升级，也可以选择其他空目录安装最新版。选择新目录后，安装登记和快捷方式会指向新目录，旧目录中的文件不会自动删除或搬迁。升级会保留授权状态、ProgramData 日志与备份、用户连接历史以及安装目录中的用户自有文件。安装后可从所有用户桌面或开始菜单的 DComEasy 快捷方式以管理员身份启动。普通权限启动时仅提示“请使用管理员权限打开本程序。”，确认后退出，不自动提权，也不进入配置界面。安装包自带 .NET 运行时，不需要现场联网或另外安装 .NET。安装器不会自动安装 OPC Core Components；需要时仍由软件按需安装或修复。旧的 Downloads 等私有目录中的解压副本不会自动迁移，安装后不要继续启动旧副本。

如果安装登记还在，但登记目录或其中的 `Uninstall.exe` 已丢失，再次运行安装包会提示此前安装目录，并显示目录选择页。选原目录会修复程序文件、卸载器和缺失的快捷方式；也可以选择新的空目录安装，成功后更新安装登记及安装器创建的快捷方式。原目录里的文件不会自动删除或搬迁，无需先手工清理注册表。正常卸载会删除 DComEasy 的安装登记；如果旧目录被手工删除，卸载器无法运行，残留登记由上述修复流程处理。

桌面入口创建在所有用户桌面。卸载时只删除仍与安装器创建时一致的 DComEasy 桌面快捷方式；若该文件后来被替换或修改，卸载器会保留它。

界面支持简体中文和英文。首次启动依据 Windows 界面语言选择，之后可在左侧栏切换并记住选择。切换语言不会清空输入或未执行的配置，也不会重复触发诊断或连接测试。

授权页和启动到期提醒中的到期时间仅显示年月日（`yyyy-MM-dd`）；实际授权到期判定仍使用原有精确时间。

拖动窗口顶部的标题或空白区域可以移动窗口；右上角按钮用于最小化、最大化/还原和关闭。输入框、按钮和表格不作为拖动区域，保留输入、点击及文字选择操作。

## 配置诊断

启动后默认显示“配置诊断”页面，不自动执行检查。点击“开始诊断”获取或刷新结果，无需输入 OPC 用户名或密码。执行配置前需先完成诊断。

诊断范围包括：

- 助手运行用户。提权后，该用户不一定等于 Windows 桌面登录用户。
- DCOM 默认属性、默认协议及角色权限。
- OPC Core Components、OPCEnum、OPC Automation DLL 与注册状态。
- OPCEnum AppID 映射、专用访问/启动/激活权限及应用认证配置；权限来源区分应用专用、机器默认和 Windows 系统默认。规则明细不代表实际远端账号已获授权。

诊断只读取本机状态，不执行配置，不启动服务。重新诊断不会覆盖尚未执行的编辑选择；退出时会提醒仍未应用的修改。

主表只展示检测结论：OPCEnum 缺少有效 AppID、空/无约束 DACL 或读取失败仍会提示；普通配置放入“排查资料”，显示允许/拒绝规则数量及认证级别，完整来源、SID 和 SDDL 可选择复制。没有连接证据时不再添加“远端识别账号／连接认证：未验证”占位行。配置资料不计入本机检测统计，导出报告单列附录，不代表远程连接通过。



## OPC 用户

在“执行配置”页面输入本地 OPC 用户名和密码，密码框内的显示按钮可切换明文显示。离开输入框或在密码框按 Enter 后，程序自动验证一次；启动时若已加载完整凭据，也会自动验证。状态图标显示验证结果，点击图标或按 Enter 可用当前输入重新验证。状态文字支持右键查看和复制完整诊断。

- **已存在的用户**：自动验证输入的凭据。密码错误时在状态栏显示错误码 1326 和诊断详情，不会覆盖、重置或修改原密码。
- **不存在的用户**：自动验证确认本地用户不存在后，“用户管理 ▾”菜单中的“创建用户”变为可用，选择后需确认创建。DComEasy 新建的本地 OPC 账户设为“密码永不过期”；执行 DCOM 配置不会隐式创建用户。
- **保存的凭据**：验证成功的凭据通过 Windows 凭据管理器保存；密码验证失败时仅保留用户名，不保存错误密码。
- **用户管理**：点击“用户管理 ▾”打开菜单。菜单始终显示“创建用户”“删除本地账户…”和“清除凭据”；只有确认本地用户不存在时才能选择“创建用户”。“清除凭据”仅清空输入及已保存的凭据，不删除 Windows 账户。“删除本地账户…”仅对 DComEasy 创建的本地 OPC 用户开放；确认账户名称和 SID 后才会删除，随后可在菜单中用当前输入重建。重建会产生新 SID，原有 DCOM 权限和文件访问可能需要重新配置。

修改用户名或密码会清除旧验证结果；输入完成后自动重新验证。输入未变化时不会重复尝试，避免频繁登录导致账户锁定。已存在用户、密码错误或账户禁用等情况下“创建用户”保持显示但不可用；程序正在执行任务时不会并发验证。状态文字可右键查看或复制完整诊断。

旧版 DComEasy 创建的账户可能受 Windows 密码最长使用期限影响。升级后，以管理员身份打开 PowerShell，在 DComEasy 安装目录先运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Repair-DComEasyOpcUser.ps1 -UserName <账户名>` 检查，再加 `-Apply` 执行一次修复。脚本只接受带 DComEasy 创建标记的本地账户；它不删除账户、不更换密码，并在执行后核对 SID、密码修改时间和到期状态。修复后回到程序点击状态图标重新验证。没有该创建标记的账户需由管理员在 Windows 用户管理中确认设置。

## 执行配置

DCOM 默认属性和权限是本机的计算机级配置，不是为某个登录用户单独保存的一套设置。权限表决定相应用户或组被授予哪些操作权限；连接测试则使用指定的 OPC 用户身份。

### DCOM 权限

权限分为四组，分别对应 Windows COM 安全中的设置：

| 权限类型 | 设置项 | 可配置权限 |
| --- | --- | --- |
| 访问权限 | 编辑限制、编辑默认值 | 本地访问、远程访问 |
| 启动和激活权限 | 编辑限制、编辑默认值 | 本地启动、远程启动、本地激活、远程激活 |

“配置诊断”用状态图标展示已有权限；“执行配置”用蓝色复选框编辑勾选状态，用户/组和状态列辅助说明当前配置。不要仅凭复选框颜色判断是否为本次新增修改，应以“预览变更”清单为准。灰色“—”表示该项不可选择。点击权限列表头可勾选或取消该列的适用项。

勾选表示保留或新增对应 Allow 权限，取消已有勾选表示在执行时移除对应 Allow 权限。请按实际需求选择，不需要将所有角色和权限全部勾选。

### 默认身份验证级别

默认选择“保持当前值”，不主动修改现有级别。可选择“无、连接、调用、数据包、数据包完整性、数据包隐私”；只有主动选择其他等级时才写入。

### 默认协议

列表包含当前及系统可用协议。勾选启用项，并拖动协议名称所在行调整优先级；拖动时会显示行影像和插入位置反馈。

至少保留一个协议。执行时按本次选择及顺序写入；取消已有协议会将其从配置中移除。

### 确认与执行结果

点击“预览变更”可重新读取当前配置并生成本次主动选择的实际变更清单，不弹出执行确认，也不会写入系统。未改动的 DCOM 权限和默认协议不会列入计划；没有修改时预览显示无需更改。若需要安装或修复 OPC 组件、启动 OPCEnum、配置默认协议或注册 DLL，可勾选“包含环境修复”再预览。点击“执行配置”时会按同一选择重新生成最新计划；没有待执行项时不写入系统。核对并确认后才执行有变更的计划，结果按步骤展示成功、失败、跳过及恢复情况。

执行失败不代表此前所有修改已撤销。执行期间可查看当前阶段、耗时及操作日志；完成后根据实际检查结果决定是否需要进一步处理。

## 组件部署与 OPCEnum

OPC Core Components 缺失、版本过旧或注册损坏时，程序按需调用随包发布的 OPC Foundation 3.1.4.132 安装包，静默安装、升级或修复。安装后会作为正常产品显示在 Windows 已安装应用列表中。

执行配置会启动尚未运行的 OPCEnum，最多等待 30 秒并复检运行状态。仅需启动服务时不重复安装组件，也不额外将服务改为开机自动启动。启动失败会显示 Windows 错误或超时原因。

安装器要求重启时，程序会保留提醒，但不会自动重启电脑；连接测试可独立执行。重启后需再次执行配置以确认服务运行状态。MSI 安装不会因等待时间较长而被强制终止，可在 `%ProgramData%\DComEasy\Logs` 中查看安装日志。

同名 OPC Automation DLL 的内容与随包版本不同时，替换信息会纳入配置确认。确认后先备份，再替换、注册和验证；注册有超时保护。

## 连接测试

1. 准备有效的 OPC 用户名和密码。
2. 在“连接测试”中填写目标主机和检测端口。点击 ProgID 右侧的查找图标，会使用已验证的 OPC 测试账户，从本机或指定主机的 OPCEnum 读取已注册服务器；查找只更新候选列表，不自动展开或回填。点击右侧下拉箭头只展开已有候选，不触发查找；选择服务器后才回填 ProgID 和 CLSID。ProgID 始终可直接手动输入；同时填写 ProgID 和 CLSID 时 CLSID 优先。未发现结果时提示“未发现已注册的 OPC DA Server”。DA 1.0/2.0/3.0 注册类别及最终连接成功的版本只记录在日志中，不在下拉框中重复显示。
3. 点击测试按钮，查看“本次连接结果”中的结论、原因和建议。

空输入框的样例仅用于说明，聚焦后隐藏，不会作为实际参数提交。

测试按钮在空闲时可直接点击；缺少用户名或密码时会在结果区提示补充，不会将按钮置灰。无需先运行配置诊断或执行配置，填写用户凭据和目标参数即可测试连接。每次测试先验证指定用户，再进行网络检查，并以该用户身份进行 OPC DA 激活和状态读取；不会自动触发配置诊断，也不以已有诊断结果作为测试前提。失败后可修改参数重试，本地 Automation 组件、远端激活和超时问题会分别报告。

OPC 连接前会依次检查主机解析、Ping 和指定 TCP 端口，结果区保留各项结果。Ping 无响应时仍会检查端口，因为目标可能禁止 ICMP；端口连接失败时停止后续 OPC 连接。检测端口仅用于 TCP 预检查，不改变 Windows 协商的 DCOM 通信端口。

连接测试的成功和失败均在结果区展示，不额外弹窗。本机配置通过不代表目标服务器可连接，连接测试也不等于持续的数据采集。

每次测试自动保存连接参数、测试用户、时间以及成功或失败的详细结果，密码不写入历史。打开“连接历史”页签可查看，重启程序后仍保留，并自动回填最近一次测试的目标参数，保留已保存的账号和密码。在历史记录上右键选择“回填连接参数”，可使用对应参数；右键“删除这条记录”会同时删除保存的历史文件，不改变当前连接表单。切换测试用户名时清空不匹配的密码，不自动发起测试。文件位于当前 Windows 用户的 `%LOCALAPPDATA%\DComEasy\connection-history`。节点浏览与刷新不会重复生成连接测试记录。保存失败会在操作日志中提示，本次结果仍可在当前会话查看。

### 节点浏览与监控列表

连接成功后，左侧显示第一层目录和点位，点击展开时才查询下一级。右侧是独立的监控列表，默认没有点位；仅选择左侧节点不会自动读取。在点位上右键选择“添加到监控”，可将它加入右侧，重复添加会去重。在目录上右键可添加该目录内已加载的点位，不会递归查询尚未展开的目录。

顶部支持完整点名查询：输入完整 ItemID 后按回车，可直接读取未展开的点，查询点会加入监控列表，读取失败时在对应行显示错误。当前界面不单独显示“查询点名”按钮。输入同时筛选左侧已加载节点，不影响右侧监控列表。搜索框旁的“刷新目录”和“节点名称”表头右侧的刷新图标仅重新加载左侧第一层，保留右侧监控点、当前值和刷新间隔。

右侧每行显示监控点名、当前值、质量、刷新间隔、服务器时间戳和读取错误，可横向滚动查看完整列；布尔开关量的当前值显示为 0 或 1。监控表格与连接历史均可拖选文字并通过 Ctrl+C 复制，监控表格也提供右键“复制”；最左侧复选框用于选择批量操作的点位，表头复选框支持全选、取消全选，横向滚动时保持可见；文字选择仅用于复制。新加入的点默认不勾选、关闭自动刷新；取消勾选不会停止已有监控。未勾选的点也可直接右键设置刷新间隔；右键已勾选点时，对全部勾选项批量设置。支持常用间隔、关闭刷新或自定义 1–3600 秒。右键“读取一次”只读取一轮，不开启自动刷新。右键“全选”会勾选全部监控点。正在刷新的点可右键“停止监控”，支持部分或批量停止，保留列表和最后读值，不中断其他点的读取；停止后的迟到结果不会更新该点。重新设置正数刷新间隔即可恢复。右键“移除选中监控”或按 Delete 移除点位并停止后续刷新。

定时刷新仅处理监控列表中已启用刷新的点，不会读取其他浏览到的节点。离开节点页或隐藏窗口时暂停；后台请求串行执行，不积压重叠请求。刷新时保留行选择和滚动位置，上方按钮状态不随自动刷新切换，页面仍可操作。手动查询、刷新目录或读取选中点时，优先取消正在等待的自动请求，再执行手动操作。质量不良或不确定会明确显示，失败会在对应行显示错误，不将旧值伪装为新的有效值。

修改目标或用户凭据会清空监控列表和旧节点，需重新测试连接；监控列表及间隔仅保留在当前目标会话中。节点操作不会覆盖已保存的连接测试结果。每个目录单次最多获取 10,000 个直接下级，并限制结果大小和耗时，超限会提示列表不完整；长值和大型数组以截断文本显示。

## 多点监测任务与趋势报告

“监测任务”用于同一 OPC DA 服务器上的长期多点采集。可从节点浏览器或监控列表右键选择“添加到监测任务…”，也可在任务页新建。监控列表对已勾选行执行批量添加；右键未勾选行时只添加当前点。重复 ItemID 会去重，添加后不会自动开启检测。

任务内 1～64 个点使用相同的 1～3600 秒整数周期，并在同一个 OPC Group 中每轮调用一次批量读取。客户端采样时间用于共同趋势时间轴；服务器返回的 OPC 原始时间戳原样保留。时间戳重复不代表异常。布尔开关量按 false=0、true=1 显示和绘制，也可用于数值阈值规则；原始类型仍记录为 Boolean。单点失败或坏质量会留下空档，其他点仍保留该轮数据，曲线不会跨空档连接旧值。

“新建任务”窗口只填写任务名称，保存一个没有点位、规则和输出目录的空任务；保存后再从对应行的“配置”添加点位并设置采样间隔、触发规则和报告目录。从点位右键新建时仍自动带入所选点位，但创建窗口不展开配置。保存、加载和添加点位不会启动任务；程序重启后任务仍需手动启动。连接和 OPC 用户来自现有配置页及连接测试页，任务窗口不重复设置；启动时固定本次连接与身份，后续修改页面输入不影响运行任务。点位来源服务器必须与启动时的服务器一致。

配置页的“添加点位”自动测试系统当前配置的服务器及用户，成功后直接打开节点树，不必先手动到连接测试页操作；展开分支加载点位，可跨分支批量选择。左键点击点位名称或复选框都能切换勾选状态，右键复制不改变勾选，分支不是可采集点。已有点位会标记且不能重复添加，任务最多 64 个点。服务器与任务不符时提示，不擅自切换；连接失败提示具体原因、阶段、错误码和建议，内容可复制，不展示调用栈。点位表提供复选框、全选表头和从 1 开始连续更新的序号；“移除点位”只处理勾选项，文字选择仍用于复制。“设为触发点”使用当前行；移除触发点会清空对应选择。采样间隔和触发前后时长均直接输入，不显示增减箭头；右侧提示图标说明有效整数范围。非法输入会显示包含字段及范围的可复制提示，修正前不能保存。

任务必须先启用数值阈值规则，并从任务点位中选择触发点、设置有效比较条件和阈值，才能点击对应行的“启动”；配置不完整时启动图标不可用，悬停会说明缺少的设置。启动后全部点位按统一周期采集和检测，切页、最小化和隐藏窗口不会暂停，报告目录会在启动前检查。未配置触发规则仍可通过“查看趋势”临时采集和查看全部点位趋势，但不会启动任务或生成报告。点击“停止”结束采集和检测，保留本次趋势；再次启动建立全新的采样缓冲。启动准备、排队和运行期间不能修改配置、添加或移除点位、删除或重复启动任务；仍可查看趋势、采样明细和事件报告，也可停止任务。停止后才能修改配置。

数值规则支持 `<`、`≤`、`>`、`≥`、`=`。等于按有效数值精确比较，首次满足时触发，持续相等不重复触发，有效不等值恢复后才能再次触发；读取失败和坏质量既不触发也不恢复。事件仍在收集后段时如再次恢复并满足条件，会创建可重叠的独立事件。

启动前条件校验失败时恢复原来的未启动或已停止状态，保留可复制的错误，不创建采集会话、不更新任务启动时间；不会因此启用“停止”。真正运行后的异常仍支持停止。趋势窗口仅显示“实时趋势”“采样明细”两个简洁标签，时间轴与最近 1000 条明细规则不变。

每个事件使用配置的触发前后窗口，分别可设为 0～60 秒；新任务默认前后各 30 秒。旧配置超过 60 秒时加载为 60 秒，任务保留，原配置文件在用户保存前不会改写。运行开始较晚、读取空档或提前退出时只保存实际数据，并在报告中标注不足，不补造样本。实时趋势和 PDF 将全部点位画在同一个坐标系内，共用时间轴与数值轴，以不同颜色区分，采样圆点粗于连线；PDF 的点位清单显示曲线色标，实时图不显示常驻图例。实时趋势默认显示最近 1 分钟，标题右侧可切换 1～5 分钟；切换立即改变可见范围，不重新连接或清空采样，有规则的任务也保留至少 5 分钟近期数据供趋势查看。实时图不直接标注各采样点的时间和值；鼠标靠近任意采样点时，按该轮客户端采样时间列出任务全部点位的值或异常状态，单点任务使用相同格式。悬停行仅显示点名及对应曲线色标；空白区域不显示无关点信息。PDF 的共同时间轴只显示时间刻度，样本少时只在不碰撞处标注数值；采样值摘要按触发轮前后各三轮及触发轮，最多七个真实时刻，在图下或续页列出各点数值或异常状态，不足时不补造，完整记录见 CSV。图中仍标出触发时刻和触发点阈值；CSV 每轮每点一行，包含客户端采样时间、值、质量、OPC 原始时间戳和完整读取错误。

输出结构为“输出目录／任务名称／触发时间／监测报告.pdf、采样数据.csv”。非法 Windows 文件名会被处理；触发目录使用本地时间，通常精确到秒，同秒重名时追加毫秒，仍重名则追加序号，不覆盖旧报告。配置时检查任务归档名称是否已被其他任务或现有文件、目录占用；已配置任务可继续使用自己的归档目录。不新建所有权、事件占位或报告临时文件。生成失败时事件快照和已成功文件会保留，可重试；表格与完整错误支持选择、Ctrl+C 和右键复制。

页面顶部仅提供“新建任务”，任务列表卡片标题右侧提供“刷新任务列表”。刷新重新读取磁盘上的任务与报告记录，更新未运行任务的增删改和报告数；外部删除运行中任务的配置不会中断采集，该任务停止后再次刷新才从列表移除。任务文件损坏时显示可复制原因，不以不完整读取结果误移除任务。每行操作列提供配置、查看趋势、启动、停止和删除五个图标，悬停显示名称；操作针对自身任务，也可通过左右键选择、Enter 执行。“配置”可添加、移除点位并设置采样与规则；运行中不可修改。“查看趋势”随时打开全部点位共用的实时趋势图：未运行任务临时采集点位，不改变任务启动状态，也不检测规则或生成报告；关闭窗口停止临时采集。任务已运行时使用其已有采样，不另开采集；任务启动、停止或修改后视图切换相应数据源。空任务提示先添加点位；连接失败提供可复制错误及重试入口。“采样明细”展示最近 1000 条数据，完整事件数据见 CSV。暂停视图刷新不会停止后台采集。

采样明细首列为“数据时间”，显示 OPC 原始时间戳的本地时间，格式为“年-月-日 时:分:秒.毫秒”；不显示客户端采样时间，原始时间戳缺失时留空，不用客户端时间替代。客户端采样时间仍用于趋势对齐，并保存在 CSV 中。采样明细各列随窗口宽度调整，避免横向滚动；读取错误较长时悬停显示全文，也可选择单元格后按 Ctrl+C 或右键复制完整内容。“全部点位趋势”标题右侧为 40×40px 的蓝底白色暂停/继续按钮（图标 22px，随 DPI 缩放），仅冻结或恢复视图刷新，悬停可查看说明，恢复时立即显示最新采样。采样提示位于趋势卡片内底部，与内容左边缘对齐，上下留白；完整错误支持滚动查看、选择和复制。

任务列表不再显示“采集状态”“最近触发”和“错误详情”列；操作列位于最后，列宽随页面分配，点位数和间隔居中。“任务启动时间”显示本次实际启动时间，停止后保留、重启后更新；未配置触发规则的任务不会启动，但查看趋势仍可临时采集。“报告数”为已完成报告数量，有报告时为深色可点击链接，点击打开任务归档目录；历史报告分布在多个目录时提供目录选择和复制列表，0 不打开目录。失败报告可右键重试，错误通过右键“查看错误详情”“复制错误详情”访问，不占表格列。删除任务仅删除配置，不删除已生成报告。

“添加到监测任务”通过复选框选择一个或多个同服务器任务，分别合并点位并去重；运行中的任务不可勾选。批量添加中单个任务失败不影响其他任务，失败详情汇总显示并可复制。全部曲线共用一个绘图区，增加点位不新增分图。连接测试页自动刷新也按固定节拍发起读取，完成即显示，慢读取不重叠、不连续补读；受通信耗时和界面调度影响，实际读取可能延迟。

开始检测前检查输出目录可写；停止或退出时如仍有未完成事件，会提示并保存标注后段不足的部分报告。报告队列已落盘但尚未完成的事件在下次启动继续生成，不自动恢复检测。快照落盘失败的数据保留在内存中，必须重试成功后再退出；连续积累 32 个快照保存失败事件时暂停新增触发，采集继续，避免失败事件无限占用内存。滚动采样缓冲按点数、间隔和最大事件窗口有界保留；极大点数/窗口配置的内存占用高于普通配置。

## 网络检测与本机端口放行

“网络检测”可独立使用，无需填写 OPC 凭据。输入目标主机和检测端口后，点击“开始检测”查看 Ping、目标 TCP 连通性、本机 TCP/UDP 监听、当前防火墙状态和 TCP 端口规则摘要。通常显示 6 行；同时使用多个网络时，分别显示其防火墙状态。主机解析仅在失败时显示，规则仅统计当前网络已启用且端口匹配的入站规则，不逐条展开。异常项保留原因和提示。“范围”列区分目标检查与本机信息；不会读取远端防火墙配置。

在“本机端口开放”中配置端口和 TCP/UDP 协议，点击“＋ 添加端口”可增加独立配置行；勾选要处理的行，点击“开放已选端口”即一次执行。默认提供 TCP 135；新增行默认勾选，支持移除。适用网络固定为本机当前网络，不需要选择。程序先校验全部勾选行，再添加对应的入站允许规则并回读验证；相同端口与协议合并处理，已存在的相同规则会复用，同名但内容不同的规则不会被覆盖。单项失败不影响后续端口，结果区显示本批次逐项结果及新增、已存在、失败数量。放行规则后，对应服务仍需处于监听状态。

放行规则不会启动服务，也不能覆盖阻止规则或域策略。结果中的“规则已保存”不代表远端一定可连接；需结合本机监听和目标连通性检查。

## 导入和导出加密配置模板

Pro 与企业版可将“执行配置”页面当前填写的内容导出为加密 `.dc` 文件，交给另一台电脑继续配置。导出的内容以页面草稿为准，不要求导出电脑已执行或验证成功；其中包括用户名、密码、默认身份验证级别、DCOM 权限、协议顺序以及是否修复环境组件。连接测试的主机、ProgID、CLSID、检测端口、连接历史和 RPC 端口设置不包含在模板中。

1. 在“执行配置”页面检查当前内容，切换到右侧卡片的“配置模板”标签，点击“导出配置”并保存 `.dc` 文件。导出不要求设置额外密码。
2. 在目标电脑切换到“配置模板”标签，点击“导入配置”并打开 `.dc` 文件。只有文件所含配置项与当前客户端的配置架构完全一致时才允许导入；文件不使用 V1/V2 之类的手工版本选项。
3. 导入只回填页面草稿，不会立即修改系统。用户名和密码均可继续编辑，并以最终输入为准。本机没有该用户名时，软件会显示用户名并询问是否先创建账户；新建账户即使之后取消或配置失败也会保留。
4. 先点击“预览变更”核对将执行的操作，再点击“执行配置”。若执行途中失败，软件会继续尝试回滚此前已完成的可逆配置，并在可复制的结果详情中分别显示执行和回滚结果；组件安装等不可逆步骤会明确列出。

`.dc` 文件由 DComEasy 自动加密并进行完整性校验，文件损坏或内容被篡改时会拒绝导入，无需另行传递密码。由于模板包含可用于创建或配置本地账户的敏感凭据，仍应只通过可信渠道传递并妥善保管。

## 导出诊断报告

完成诊断后，点击“配置诊断”右上方的导出图标，悬停可查看“导出诊断报告”说明。

1. 选择报告格式。当前版本可选无水印 PDF 或 HTML。每次打开均默认选中 PDF。
2. 选择保存位置和文件名；覆盖已有文件前需要确认。
3. 导出成功后，页面顶部短暂显示成功提示，保存路径记录在操作日志中。报告不会自动打开。

报告使用最近一次完成的诊断快照，包含检查时间、计算机、软件版本、运行用户、基础配置、DCOM 角色权限及默认协议。它不代表实时状态或连接测试结果，不包含密码、凭据、原始日志和未执行的勾选修改。

PDF 为文字可选择、复制的横向 A4 文档，内嵌中文字体，长表格自动分页并重复表头。HTML 为无外部依赖的单文件。两种格式均使用导出时的界面语言。没有诊断结果或其他操作进行中时，导出按钮不可用。
