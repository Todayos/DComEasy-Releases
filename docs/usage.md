# DComEasy 使用指南

[返回首页](../README.md) · [English](usage.en.md) · [下载最新版本](https://github.com/Todayos/DComEasy-Releases/releases/latest)

## 安装与启动

1. 从本仓库的 [Releases](https://github.com/Todayos/DComEasy-Releases/releases) 下载完整离线安装包。
2. 右键安装程序，选择“以管理员身份运行”。
3. 安装完成后，从开始菜单启动 DComEasy。
4. DComEasy 需要管理员权限读取和修改系统级 DCOM 配置；普通权限启动时会显示提示并退出。

安装包已包含所需的 .NET 运行时。请勿只复制安装目录中的 `DComEasy.exe`，否则依赖组件可能不完整。

安装新版时无需先卸载旧版。先关闭 DComEasy，再以管理员身份运行新版安装包；目录页默认显示原安装位置，保留该目录即可原地升级，也可选择其他空目录。选择新目录后，快捷方式会指向新版本，旧目录文件不会自动删除。授权状态、日志、连接历史和用户自有文件会保留。

## 配置诊断

进入“配置诊断”，点击“开始诊断”。程序会读取本机 OPC DA / DCOM 相关状态，包括基础配置、组件、权限和协议设置。诊断本身不会修改系统配置或启动服务。

诊断结果按状态显示原因和处理建议。需要留档时，可在诊断完成后导出无水印 PDF 或单文件 HTML。

## OPC 用户凭据与账户

在“执行配置”页面输入本地 OPC 用户名和密码。离开输入框或在密码框按 Enter 后会自动验证；状态图标显示结果，点击图标可重试。状态文字可右键查看或复制完整诊断。已存在账户的密码不会被覆盖或重置。

“用户管理 ▾”菜单始终显示“创建用户”“删除本地账户…”和“清除凭据”。只有验证确认本地账户不存在时，“创建用户”才可用；新建账户的密码设为永不过期。“清除凭据”只清除输入和已保存的凭据。“删除本地账户…”只用于 DComEasy 创建的本地 OPC 账户，删除前会核对名称和 SID；重建账户会产生新 SID，可能需要重新配置 DCOM 权限。

旧版 DComEasy 创建的账户若受密码期限影响，请以管理员身份在安装目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Repair-DComEasyOpcUser.ps1 -UserName <账户名>` 先检查，再加 `-Apply` 修复。脚本仅处理带 DComEasy 创建标记的本地账户，不删除账户，也不更改密码。

## 执行配置

进入“执行配置”后：

1. 输入 OPC 用户信息并等待自动验证；如需创建本地用户，从“用户管理 ▾”菜单选择“创建用户”。
2. 按需选择身份验证级别、协议和 DCOM 权限。
3. 点击“预览变更”，检查即将写入或移除的设置。
4. 确认无误后执行配置，并查看每一项结果。

DCOM 设置会影响系统安全和远程访问。执行前应核对目标环境的安全要求，并只选择实际需要的权限。

## OPC DA 连接测试

连接测试可以独立使用，无需先运行诊断或执行配置：

1. 在“执行配置”中验证用于连接的 OPC 用户。
2. 进入“连接测试”，填写目标主机和检测端口。
3. 输入 OPC 服务器的 ProgID 或 CLSID；两者同时填写时优先使用 CLSID。
4. 点击“测试连接”，查看网络检查、服务器激活和状态读取结果。

成功和失败的测试都会写入连接历史，但不会保存密码。错误详情和表格内容支持复制，便于提交给维护人员。

## 节点浏览与监控

连接成功后，可以展开 OPC 节点目录，或输入完整 ItemID 查询点位。将点位加入监控列表后，可通过右键菜单：

- 读取一次；
- 设置 1–3600 秒的刷新间隔；
- 对已勾选的多个点位批量设置刷新；
- 停止监控或移除点位；
- 复制当前值、质量、时间戳和错误信息。

布尔开关量在监控列表和趋势图中显示为 `0/1`；服务器实际返回空值时仍显示空值。点位和刷新设置只保留在当前目标会话中。

## 多点监测任务与报告

进入“监测任务”后，可先创建仅有名称的空任务，再通过行内“配置”添加点位。点位可从当前连接的服务器树中批量选择，也可从节点浏览器或监控列表右键添加；任务复用系统中已配置的 OPC 连接和用户信息。任务列表右上角可手动刷新，以同步磁盘上被新增或删除的任务记录。

点位添加后，点击任务行的趋势图标即可查看全部点位的实时趋势：即使任务尚未启动或尚未设置触发规则，也会临时采样；关闭趋势窗口后临时采样停止，不生成报告。趋势默认显示最近 1 分钟，可在窗口中调整至最长 5 分钟。

要启动任务检测，需至少配置一个点位、触发点、数值比较条件与阈值，以及可写的报告目录。采样间隔为 1–3600 秒，任务内所有点位按同一周期批量读取。触发前后时长默认各 30 秒。只有触发点的有效采样满足规则时才记录事件；恢复后再次满足可再次触发。每个事件自动归档包含全部点位的 PDF 报告和 CSV 采样数据。任务运行中只能查看，修改配置请先停止；重新启动会记录新的任务启动时间。

## 网络检测

进入“网络检测”，输入目标主机和端口后开始检测。远程目标会检查主机解析、Ping 和 TCP 端口；检测本机时还会显示监听状态和当前防火墙规则摘要。

可以批量添加本机 TCP 或 UDP 入站规则。添加规则只代表防火墙允许该端口，相关服务仍需处于监听状态。

## 离线授权与联系开发者

DComEasy 2.0.2 始终启用离线授权，不要求现场联网。未激活时使用 Free 基础功能；Pro 和企业版功能需要有效的 32 位激活码。侧栏“授权”页面显示当前授权状态、版本功能对比和激活入口；“联系开发者”提供 GitHub 地址和邮箱。

## 常见问题

### 已完成本机配置，但仍无法连接远程 OPC DA 服务器

本机配置完成不代表远端主机、账号、网络和防火墙均已就绪。请运行连接测试，并根据失败阶段检查目标端口、远端 OPC 服务、DCOM 权限及用户凭据。

### Ping 失败，但端口检查成功

目标主机可能禁用了 ICMP。DComEasy 会继续执行端口检查，应以各检查项的实际结果为准。

### 找不到 OPC 节点

确认 OPC 服务器允许枚举节点，并尝试刷新目录或使用完整 ItemID 查询。部分服务器不会公开完整的层级目录。

### 如何反馈问题

先搜索[现有 Issues](https://github.com/Todayos/DComEasy-Releases/issues)，再通过[问题模板](https://github.com/Todayos/DComEasy-Releases/issues/new?template=bug_report.yml)提交 DComEasy 版本、Windows 版本、复现步骤和完整错误内容。上传前请移除密码、激活码、账号、主机名和 IP 地址等敏感信息。
