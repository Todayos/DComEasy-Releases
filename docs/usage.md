# DComEasy 使用指南

[返回首页](../README.md) · [English](usage.en.md) · [下载最新版本](https://github.com/Todayos/DComEasy-Releases/releases/latest)

## 安装与启动

1. 从本仓库的 [Releases](https://github.com/Todayos/DComEasy-Releases/releases) 下载完整离线安装包。
2. 右键安装程序，选择“以管理员身份运行”。
3. 安装完成后，从开始菜单启动 DComEasy。
4. DComEasy 需要管理员权限读取和修改系统级 DCOM 配置；普通权限启动时会显示提示并退出。

安装包已包含所需的 .NET 运行时。请勿只复制安装目录中的 `DComEasy.exe`，否则依赖组件可能不完整。

## 配置诊断

进入“配置诊断”，点击“开始诊断”。程序会读取本机 OPC DA / DCOM 相关状态，包括基础配置、组件、权限和协议设置。诊断本身不会修改系统配置或启动服务。

诊断结果按状态显示原因和处理建议。需要留档时，可在诊断完成后导出 PDF；专业版还可导出单文件 HTML。

## 执行配置

进入“执行配置”后：

1. 输入 OPC 用户信息并完成验证；如需创建本地用户，可使用专业版的创建功能。
2. 按需选择身份验证级别、协议和 DCOM 权限。
3. 点击“预览变更”，检查即将写入或移除的设置。
4. 确认无误后执行配置，并查看每一项结果。

DCOM 设置会影响系统安全和远程访问。执行前应核对目标环境的安全要求，并只选择实际需要的权限。

## OPC DA 连接测试

连接测试可以独立使用，无需先运行诊断或执行配置：

1. 在“执行配置”中验证用于连接的 OPC 用户。
2. 进入“连接测试”，填写目标主机和检测端口。
3. 输入 OPC 服务器的 ProgID 或 CLSID；两者同时填写时优先使用 CLSID。
4. 点击“测试连接”，查看网络检查、服务器激活和状态读取结果。

成功和失败的测试都会写入连接历史，但不会保存密码。错误详情和表格内容支持复制，便于提交给维护人员。

## 节点浏览与监控

连接成功后，可以展开 OPC 节点目录，或输入完整 ItemID 查询点位。将点位加入监控列表后，可通过右键菜单：

- 读取一次；
- 设置 1–3600 秒的刷新间隔；
- 对已勾选的多个点位批量设置刷新；
- 停止监控或移除点位；
- 复制当前值、质量、时间戳和错误信息。

点位和刷新设置只保留在当前目标会话中。

## 网络检测

进入“网络检测”，输入目标主机和端口后开始检测。远程目标会检查主机解析、Ping 和 TCP 端口；检测本机时还会显示监听状态和当前防火墙规则摘要。

专业版可以批量添加本机 TCP 或 UDP 入站规则。添加规则只代表防火墙允许该端口，相关服务仍需处于监听状态。

## 授权

“授权”页面显示当前版本、授权状态、授权方式和到期时间。专业版使用可复制到客户机的 16 位离线激活码；请勿在公开 Issue、截图或日志中提交激活码。

## 常见问题

### 已完成本机配置，但仍无法连接远程 OPC DA 服务器

本机配置完成不代表远端主机、账号、网络和防火墙均已就绪。请运行连接测试，并根据失败阶段检查目标端口、远端 OPC 服务、DCOM 权限及用户凭据。

### Ping 失败，但端口检查成功

目标主机可能禁用了 ICMP。DComEasy 会继续执行端口检查，应以各检查项的实际结果为准。

### 找不到 OPC 节点

确认 OPC 服务器允许枚举节点，并尝试刷新目录或使用完整 ItemID 查询。部分服务器不会公开完整的层级目录。

### 如何反馈问题

先搜索[现有 Issues](https://github.com/Todayos/DComEasy-Releases/issues)，再通过[问题模板](https://github.com/Todayos/DComEasy-Releases/issues/new?template=bug_report.yml)提交 DComEasy 版本、Windows 版本、复现步骤和完整错误内容。上传前请移除密码、激活码、账号、主机名和 IP 地址等敏感信息。
